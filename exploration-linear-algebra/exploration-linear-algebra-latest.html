线性代数：从几何直觉到 LLM 与 Agent 安全

矩阵怎样改变信息，模型怎样选择和混合信息，安全分析又能从这些变化里看见什么？从一支二维箭头开始，把计算、几何与研究问题连接起来。

01

先把向量看成一个对象，再选择坐标

向量表示可相加、可缩放的量；坐标是我们记录它的一种方式。

把一次网络连接写成 x=(字节数, 持续时间, 失败次数)ᵀ，已经在做向量化：把一个复杂对象压进有序的实数列表。这里的三个数有不同单位，不能直接把“长”解释为“危险”。先辨认每个坐标的意义，再决定缩放、标准化和比较方式。向量空间的加法是逐坐标相加；数乘把每个坐标乘以同一标量。神经网络的隐藏向量也遵守这些运算，却通常没有每个坐标对应一个人类概念的保证。

本教程的几何推导默认实数域和列向量：x∈ℝⁿ，A∈ℝᵐˣⁿ，Ax∈ℝᵐ。转置 xᵀ 把列写成行。向量相同不代表输入对象相同：如果特征提取只记录总流量，它就已经丢掉包顺序。研究 LLM 的表示时，也应先问表示来自哪个层、哪个 token、哪个模型，以及前处理是什么。

x=(3,4)ᵀ，y=(4,0)ᵀ xᵀy=12；‖x‖₂=√(3²+4²)=5 cos θ=(xᵀy)/(‖x‖₂‖y‖₂)=12/(5×4)=0.6

欧氏距离关心差值的绝对长度，余弦相似度关心方向。对非零向量，余弦忽略正数缩放：x 与 100x 的余弦为 1，却可能表示完全不同的流量规模。点积同时受角度和范数影响。零向量没有可定义的余弦；工程实现中的小常数只是避免除零，不会给它凭空增加方向。

把相似度当作检索信号很有用，把相似度当作权限、可信度或同一意图的证明则超出了公式。度量是否合理取决于表示和任务；高维直觉应通过分布、标注和对照实验检查。

练习：x=(1,1)，y=(2,2)，z=(1,−1)。谁与 x 最相似？

按余弦，y 与 x 为 1，z 与 x 为 0；按欧氏距离，‖x−y‖=√2，‖x−z‖=2。这个例子里两种比较顺序一致，但含义不同。再比较 y 与 100x：方向完全一致，距离很大。为流量检测选择度量时，要先决定是否希望规模变化影响判断。

基础定义与几何解释：MIT 18.06；Mathematics for Machine Learning，第 2–3 章。

02

矩阵的每一列，是一支基向量的去向

读矩阵乘法时，不要先背行乘列；先看整个坐标网格发生了什么。

线性映射 T 满足 T(αx+βy)=αT(x)+βT(y)。这保证知道基向量的去向后，就知道所有向量的去向。二维标准基是 e₁=(1,0)ᵀ 和 e₂=(0,1)ᵀ；矩阵 A 的两列分别是 Ae₁、Ae₂。因此 A(x₁,x₂)ᵀ=x₁Ae₁+x₂Ae₂。矩阵不是一张静态数字表，而是一套同时作用于所有输入的规则。

A=[1 1; 0 1]，e₁↦(1,0)ᵀ，e₂↦(1,1)ᵀ x=(1,1)ᵀ=e₁+e₂ ⇒ Ax=(2,1)ᵀ det(A)=1×1−1×0=1

这个变换把单位正方形剪切成平行四边形。行列式给出有符号面积缩放：绝对值为面积倍数，负号表示定向翻转。二维行列式为零时，两个输出基向量共线，整个平面压进一条线或一个点。行列式只适用于方阵；高维信息损失更普遍的语言是秩和零空间。

动手：剪切、旋转与塌缩

二维合成示例
Ax=(2.000, 1.000)ᵀ；det=1.000；rank=2；单位面积变为 1.000。

默认剪切保留所有输入信息。改成秩 1 后，不同输入可能落到同一点；图形塌缩不表示某一种语义自动被删除。网格会随视图缩放，数值输出是判断面积倍数的依据。

矩阵复合有顺序：BAx 表示先 A 后 B，一般 AB≠BA。神经网络里常见 Wx+b 是仿射映射，除非 b=0，它不会把原点映到原点，所以不属于严格线性映射。再接 ReLU、softmax 或门控，整个网络更不是单个矩阵；但每一段线性运算仍然能局部拆解和检查。

练习：A=[1 2; 0 0]。哪些输入会变成零？

Ax=(x₁+2x₂,0)ᵀ；变成零的条件是 x₁=−2x₂，所以所有 t(−2,1)ᵀ 都在零空间。矩阵的第一行保留一个线性组合，第二行没有提供新信息。任意两个相差这个零空间方向的输入都产生相同输出。

03

秩告诉你：保留了几种独立变化

方程有没有解、解是否唯一、哪些输入无法辨认，是同一个几何问题的三个侧面。

列空间 Col(A) 是所有 Ax 可能到达的输出；零空间 Null(A) 是所有被映成零的输入。秩是列空间维数，也等于行空间维数。对 A∈ℝᵐˣⁿ，秩–零度公式是 rank(A)+dim Null(A)=n：输入中的 n 个独立自由度，分成被保留的部分和被压掉的部分。

贯穿例子：A=[1 0; 1 1; 0 1]∈ℝ³ˣ² a₁=(1,1,0)ᵀ，a₂=(0,1,1)ᵀ，rank(A)=2 Ax=(x₁, x₁+x₂, x₂)ᵀ，因此输出必须满足 y₂=y₁+y₃ b=(1,2,2)ᵀ 不满足 2=1+2，所以 Ax=b 无精确解

这里没有输入信息损失：两列独立，Null(A)={0}。但输出空间是三维里的二维平面，某些目标永远不可达。“无法拟合这个输出”和“不能恢复输入”不是同一件事。消元只是在系统地找独立约束；初等行操作保留方程组的解集合，而不应被误解成原始特征的语义保持。

能否到达 b？b∈Col(A) 才有解。
到达后能否区分输入？Null(A)={0} 才最多一个解。
无法到达的分量在哪里？Col(A) 的正交补是 Null(Aᵀ)。

贯穿例子的左零空间由 n=(1,−1,1)ᵀ 张成，因为 Aᵀn=0。任何模型预测 Ax 都与 n 正交；目标中沿 n 的部分必须成为残差。这将直接解释下一节的最小二乘。不要把左零空间和输入零空间混淆：前者在 ℝᵐ 中描述无法解释的输出方向，后者在 ℝⁿ 中描述无法观察的输入方向。

安全特征工程中的秩缺陷可能来自重复传感器或冗余特征，也可能来自有意压缩。低秩本身没有“安全”或“危险”的标签；要追踪丢掉了哪些变化，以及攻击者是否能利用这些不可见方向。浮点计算还要区分精确秩与按阈值定义的数值秩。

练习：只观察两个传感器的总和 s=x₁+x₂，能识别谁贡献了流量吗？

观察矩阵为 [1 1]，秩 1，零空间由 (1,−1)ᵀ 张成。(3,2) 与 (4,1) 都得到 s=5，因此不能仅从 s 还原来源。增加独立观察 t=x₁−x₂ 后，矩阵 [1 1; 1 −1] 满秩，两个未知量才可以唯一恢复。

04

换一组基，关系仍在，坐标会变

表示中的“第 317 维”没有天然语义；方向和子空间往往比单个坐标更稳健。

基是一组线性独立且张成整个空间的向量。把基向量放进可逆方阵 B 的列中，原坐标和新坐标满足 x=Bc，所以 c=B⁻¹x。变化的是描述对象的数值，向量所表示的对象没有因此变化。若输入和输出都使用这组基，同一个线性算子的矩阵变为 B⁻¹AB；这叫相似变换。

B=[1 1; 1 −1]，x=(3,1)ᵀ c=(2,1)ᵀ，因为 2(1,1)ᵀ+1(1,−1)ᵀ=(3,1)ᵀ B⁻¹=(1/2)[1 1; 1 −1]

正交矩阵 Q 满足 QᵀQ=I，逆就是转置。换到正交基时，长度和点积保持：‖Qᵀx‖₂=‖x‖₂。这解释了为什么 PCA 的正交旋转不会凭空改变数据总能量，只是把变化重新排列到不同坐标轴。如果基不是正交的，新坐标的普通点积不再自动等于原空间点积；需要相应的度量矩阵。

可逆不代表容易数值求解。两支基向量几乎平行时，要靠两个很大的反向系数表示一个很小的垂直分量，微小测量误差就会导致很大的坐标变化。这是病态问题，而不是“计算机算错了”。实际解 Ax=b 时优先调用线性求解器，不先显式形成 A⁻¹；下一阶段会用奇异值量化不稳定性。

表征研究里，一个正交旋转可以把原来集中在单坐标的信号分散到许多坐标，同时保持线性可解码性。观察到某个神经元与标签相关，是有用线索；声称它是概念的唯一载体，需要干预和对照证据。

练习：若 Q 是二维 90° 旋转，x=(3,4)ᵀ，旋转后的范数会变吗？

Q=[0 −1; 1 0]，Qx=(−4,3)ᵀ，范数仍为 5。因为 QᵀQ=I，(Qx)ᵀ(Qx)=xᵀx。反射也是正交变换，却会改变定向；是否保持长度与是否保持定向要分开判断。

05

无法精确解释时，找最近的可解释分量

最小二乘把目标拆成列空间中的预测与垂直于列空间的残差。

先投影到一条直线。给定非零方向 a，要在所有 ca 中寻找最接近 b 的点。最短距离处，残差 b−ca 与 a 垂直，所以 aᵀ(b−ca)=0，得到 c=(aᵀb)/(aᵀa)。这是几何约束推导出的公式，和“把二维箭头的影子投到斜线”是同一件事。

动手：投影与岭回归的收缩

方向固定 a=(1,1)ᵀ
λ=0.000；c=(b₁+b₂)/(2+λ)=1.500 预测=(1.500, 1.500)ᵀ；残差=(0.500, −0.500)ᵀ aᵀ残差=0.000；‖残差‖₂=0.707

默认 λ=0 是正交投影。λ>0 最小化 ‖ca−b‖²+λc²，系数收缩，残差一般不再垂直于 a。它仍预测在同一条直线上，却不是距离 b 最近的点。

对一般矩阵，最小化 ‖Ax−b‖₂²，一阶条件是 Aᵀ(Ax−b)=0。满列秩时得到唯一解 x̂=(AᵀA)⁻¹Aᵀb。这适合推导，不代表实现时要显式求逆；QR 或 SVD 求解通常更稳健，因为形成 AᵀA 会平方二范数条件数。列不独立时，最小二乘预测仍唯一，系数可能不唯一；伪逆 A⁺b 选择最小范数的解。

贯穿例子：AᵀA=[2 1; 1 2]，Aᵀb=(3,4)ᵀ x̂=(2/3,5/3)ᵀ；Ax̂=(2/3,7/3,5/3)ᵀ r=b−Ax̂=(1/3,−1/3,1/3)ᵀ；Aᵀr=0；‖r‖²=1/3

QR 分解给这件事另一种计算组织。满列秩 A 可以写成 A=QR，Q 的列是列空间的正交基，R 是可逆上三角矩阵。先求目标在这些基上的坐标 Qᵀb，再用回代解 Rx=Qᵀb；预测就是 QQᵀb。Gram–Schmidt 展示“逐个减掉已有投影再归一化”的思路，数值库则常用更稳定的实现。

岭回归最小化 ‖Ax−b‖²+λ‖x‖²，解为 (AᵀA+λI)⁻¹Aᵀb，λ>0 时即使 A 秩亏也唯一。它通过牺牲部分拟合来抑制大系数。不同特征的缩放影响惩罚含义；给字节数和秒数的系数施加相同数值惩罚，不意味着对两种物理量公平。

线性 probe 本质上也在寻找预测标签的线性组合。良好的拟合说明标签在当前表示里可线性预测；它不证明模型在完成原任务时使用这条预测路径。数据泄漏、同源样本和模板差异都可能让 probe 学到捷径。

练习：为什么贯穿例子的残差一定沿 (1,−1,1)ᵀ？

因为最小二乘一阶条件给出 Aᵀr=0，而 A 的左零空间是一维，由 (1,−1,1)ᵀ 张成。r 正是 b 在这个方向的投影：nᵀb=1，nᵀn=3，所以 r=(1/3)n。理解这个关系后，可以先用几何检查解，再检查系数计算。

06

特征向量找不转向的方向，二次型看曲率

对称矩阵的谱把耦合的坐标问题，拆成互相正交的一维问题。

方阵 A 的特征向量 v 是满足 Av=λv 的非零向量。变换后它仍在同一直线上：λ>0 同向，λ<0 反向，λ=0 被压为零。特征值分析的是输入输出在同一空间的算子，因此不能直接给任意长方阵谈特征值。一般实矩阵可能有复特征值，也可能不能对角化。

实对称矩阵 S 的情况更好：存在正交 Q 和实对角 Λ，使 S=QΛQᵀ。把 x 换成特征坐标 z=Qᵀx，二次型变成 xᵀSx=Σᵢλᵢzᵢ²。这直接连接优化、协方差和能量。所有特征值非负时 S 为半正定（PSD）；全部严格正时为正定（PD）。仅仅“矩阵元素非负”不保证 PSD；仅仅“对角线为正”也不保证 PSD。

S=AᵀA=[2 1; 1 2] q₁=(1,1)ᵀ/√2，λ₁=3；q₂=(1,−1)ᵀ/√2，λ₂=1 xᵀSx=3z₁²+z₂²=‖Ax‖²≥0

若函数是 f(x)=½xᵀSx−cᵀx，梯度为 Sx−c，Hessian 为 S。PSD 意味着这个二次函数凸；PD 意味着严格凸并有唯一最小点。深度网络的总体损失通常不是这类全局凸二次函数，但 Hessian 的局部谱仍可描述某个点附近的曲率。局部近似有效范围与训练状态必须一起说明。

不要把谱半径和任意扰动的最大放大率混为一谈。对称矩阵可用特征值控制欧氏范数放大；非正规矩阵即使特征值很小，也可能有很大的瞬时放大。输入输出放大的一般工具是奇异值。

练习：S=[1 2; 2 1] 的元素都为正，它是 PSD 吗？

不是。其特征方向 (1,1) 对应 3，(1,−1) 对应 −1。取 x=(1,−1)ᵀ，xᵀSx=−2。只需找到一个二次型为负的向量，就能否定半正定性。

07

SVD：换到输入方向，缩放，再映到输出方向

奇异值统一描述低秩近似、能量保留、伪逆和数值不稳定。

任意实矩阵都有奇异值分解 A=UΣVᵀ。把输入写到右奇异向量坐标中，按非负奇异值 σᵢ 缩放，再沿左奇异向量输出；长方阵还可能嵌入更大空间或丢弃方向。紧致形式只保留 r 个非零奇异值，Uᵣ∈ℝᵐˣʳ，Σᵣ∈ℝʳˣʳ，Vᵣ∈ℝⁿˣʳ。U、V 的列分别正交，左右空间不必有相同维数。正交变换可能包含旋转或反射；“两次旋转”只是部分情形的二维直觉。

A=Σᵢ σᵢuᵢvᵢᵀ；σ₁≥σ₂≥…≥0 截断到 k 项：Aₖ=Σᵢ≤ₖ σᵢuᵢvᵢᵀ ‖A−Aₖ‖₂=σₖ₊₁；‖A−Aₖ‖F=√(Σᵢ>ₖ σᵢ²) 约定秩 r 之后的 σᵢ=0；k=r 时误差为 0 贯穿例子 A 的奇异值为 √3 和 1，来自 AᵀA 的特征值 3 和 1

截断 SVD 在谱范数和 Frobenius 范数下给出最佳秩至多 k 近似。这是明确的矩阵误差结论，不能直接推出“下游任务精度最佳”或“安全属性保留最佳”。能量较低的方向可能携带少见但关键的信息。反过来，数据里的大奇异值也可能是重复文本、采集偏差或流量规模，而非研究者关心的语义。

动手：保留能量与保留信息

A=R(30°) diag(3,σ₂) R(−20°)ᵀ
σ₁=3.000，σ₂=1.000；保留 1 项 相对平方 Frobenius 能量=9/10=90.0%；‖A−A₁‖F=1.000 ‖A−A₁‖₂=1.000；κ₂(A)=3.000；A₁ 的秩=1

默认保留 90% 平方 Frobenius 能量，但第二输入方向的信息全部丢失。把 σ₂ 拉到 0，完整矩阵本身奇异；把它拉到很小，求逆会很敏感。图示的旋转固定，便于只观察奇异值的影响。

二范数算子范数 ‖A‖₂=σ₁ 给出最大方向的放大率。对可逆方阵，κ₂(A)=σmax/σmin；若输入沿一个缩得很小的方向，求逆要把测量误差放大回来。贯穿例子是满列秩长方阵，也可用非零奇异值之比描述最小二乘的敏感性，但不存在普通方阵逆。秩亏时，“最大非零奇异值 / 最小非零奇异值”只是有效子空间的条件性，不等于整个问题可逆。

伪逆沿非零奇异方向乘 1/σᵢ，零奇异方向保持零。岭回归沿每个方向使用 σᵢ/(σᵢ²+λ)，避免对微小 σᵢ 无限制放大。这个滤波视角比“往对角线加一点数”更能说明正则化付出的偏差与得到的稳定性。

练习：diag(1,0.001) 的输出第二坐标误差为 0.001，逆解误差有多大？

逆矩阵为 diag(1,1000)，第二坐标误差变成 1。原矩阵条件数为 1000。误差放大取决于方向，不能简单说所有误差都放大 1000 倍；条件数描述最坏方向的相对敏感性。

08

协方差把“距离远”改写为“偏离常态方向”

PCA 找变化最大的方向，Mahalanobis 距离把不同方向的自然波动纳入比较。

把 n 个样本作为行堆叠，得到 X∈ℝⁿˣᵈ。先减去列均值得到中心化 Xc，当 n≥2 时，样本协方差为 C=XcᵀXc/(n−1)。对角线是每个特征的方差，非对角元素是共同变化；C 是 PSD，因为任意 vᵀCv=‖Xcv‖²/(n−1)≥0。它不是因果图：流量和时间共同增长不说明其中一个造成另一个。

若 Xc=UΣVᵀ，PCA 主方向是 V 的列，解释方差为 σᵢ²/(n−1)，主成分坐标是 XcV。最大方差方向是最佳线性重构方向，但未必是分类方向。是否中心化、是否标准化、样本是否代表未来环境，都会改变 PCA 的结果；做评估时，这些统计量只能从训练集拟合。

合成正常分布：μ=(0,0)ᵀ，C=diag(9,1) 欧氏距离 dE(x)=√(x₁²+x₂²) Mahalanobis 距离 dM(x)=√((x−μ)ᵀC⁻¹(x−μ))=√(x₁²/9+x₂²) x=(3,0)ᵀ：dE=3，dM=1；y=(0,2)ᵀ：dE=2，dM=2

x=(3.000,0.000)ᵀ；dE=3.000；dM=1.000 阈值 dM>2：未超出。此阈值只是演示选择，不是检测器实测阈值。

椭圆表示等 Mahalanobis 距离，不是概率保证。若数据来自二维高斯，且使用已知的总体 μ、C，则 dM² 服从 χ²₂ 分布；从有限训练集估计 μ、C 后需要不同校准，不能原样套用。多峰、重尾和漂移也可能破坏高斯假设。

白化变换 z=C^(−1/2)(x−μ) 将正定协方差下的 Mahalanobis 距离转成 z 的欧氏长度。这里 C^(−1/2) 是逆平方根：若 C=QΛQᵀ，则它是 Q diag(λᵢ^(−1/2)) Qᵀ。样本少于维度、特征重复或估计噪声较大时 C 可能奇异或病态；收缩估计、C+εI 或受限子空间是常见处理选择。使用伪逆会忽略零特征值方向，可能把训练中没有出现的新方向也忽略，必须明确检测含义。

安全异常检测的“正常”是由采集样本定义的。只用工作日流量训练，节假日任务可能被判异常；如果训练集中混入攻击，协方差也可能把攻击方向吸收到常态中。异常分数是调查线索，身份认证与访问控制需要独立证据。

练习：为何两个坐标重复会使协方差奇异？

若 x₂=x₁，所有中心化样本都在 (1,1) 方向上，(1,−1) 方向的方差为零。C 的秩至多为 1，普通逆不存在。单纯加入 εI 可以使其可逆，但引入了一个人为的方差尺度；要报告 ε 并检查它是否决定了异常排名。

梯度传回来的，是输出敏感性的线性组合

Jacobian 是非线性函数在一个点附近的局部线性地图。

对向量函数 f:ℝⁿ→ℝᵐ，Jacobian Jf(x)∈ℝᵐˣⁿ 的第 i 行第 j 列是 ∂fᵢ/∂xⱼ。小扰动满足 f(x+δ)≈f(x)+Jf(x)δ。这个近似只在局部有效；扰动跨越激活函数分段边界、改变 token 化或触发离散工具调用时，要重新评估。把文本替换当作任意连续向量扰动，也是额外的可实现性假设。

L(x)=½‖Ax−b‖² ⇒ ∇L=Aᵀ(Ax−b)，H=AᵀA 贯穿例子在 x=(0,0)ᵀ：∇L=−Aᵀb=(−3,−4)ᵀ 若 y=Wx，损失对 y 的梯度是 g，则对 x 的梯度是 Wᵀg 若 h=g(f(x))，Jh=Jg(f(x))Jf(x)

为什么反向传播里总有转置？前向把输入扰动 δx 映成 Wδx；损失变化为 gᵀWδx=(Wᵀg)ᵀδx，因此输入梯度是 Wᵀg。它不是“把矩阵乘法倒着运行”或求 W 的逆。自动微分通常计算向量–Jacobian 乘积，不显式存下整个巨大的 Jacobian。

对二次型梯度下降，更新是 xₜ₊₁=xₜ−η(Sxₜ−c)。沿第 i 个特征方向的误差乘 1−ηλᵢ。S 正定时，0<η<2/λmax 保证这个固定二次问题收敛。贯穿例子的 λmax=3，η=0.5 时两个方向的因子为 −0.5 和 0.5；这解释了一个方向会交替越过最小点。深度学习的实际学习率还受随机批次、非线性和优化器状态影响。

在固定线性近似下，‖δ‖₂≤ε 时，最大化一阶损失变化的扰动为 ε∇L/‖∇L‖₂（梯度非零时）。这是局部数学结论。实际攻击还需要满足输入约束、攻击者可访问性与成功判定；大梯度不自动等于可利用漏洞，小梯度也不保证稳健。

练习：为什么 J 的最大奇异值能衡量局部敏感性，却不能独自证明全局安全？

因为 ‖Jδ‖₂≤σmax(J)‖δ‖₂，只控制当前点的一阶变化。有限距离上的路径可能经过具有不同 Jacobian 的区域，还存在二阶误差；文本 token 和工具行为通常还有离散变化。若要全局结论，需对允许输入集合和整条路径给出额外界或验证。

隐藏表示：方向有用，语义需要证据

从 token 查表、线性读出到归一化，把模型张量的维度对齐。

若词表大小为 V、隐藏维度为 d，嵌入矩阵 E∈ℝⱽˣᵈ 的第 i 行是第 i 个 token 的向量。输入 token id 查表得到向量；这可写成 one-hot 行向量乘 E。为了贴近常见 Transformer 写法，之后把 T 个 token 按行堆叠成 X∈ℝᵀˣᵈ。单独拿出某一 token 时，可以把该行转置为几何列向量 x；这只是记号切换，不改变计算。

单 token 列向量：y=Wcol x，Wcol∈ℝᵐˣᵈ 整段 token 行堆叠：Y=XWrow，Wrow∈ℝᵈˣᵐ 两种写法对应 Wrow=Wcolᵀ；不要把维度相同误认为权重布局相同

上下文化表示会随上下文、层和位置变化。同一个字符串在不同上下文里没有保证映到同一隐藏向量。余弦检索也应区分专门训练的句向量与随手抽出的 token 激活；池化方式、范数和模型训练目标都影响度量含义。输出层常以隐藏行向量乘读出矩阵得到 logits，再用 softmax 得到词表上的概率。

RMSNorm 用均方根缩放各坐标，再乘可学习缩放参数。对单向量，它形如 RMSNorm(x)=g⊙x/√(mean(x²)+ε)。它不减均值；LayerNorm 会减均值再按方差缩放。忽略 ε 与 g 时，正比例缩放输入会被消去，但实际实现中 ε、可学习参数和周围残差结构都影响行为。归一化是依赖 x 的非线性运算，不能全局看作一个固定矩阵。

残差连接把子模块输出加回输入：h←h+f(h)。这使许多层在同一个隐藏维度里读写，但“共享空间”不表示所有层的同一方向具有完全相同语义。研究方向干预必须固定干预位置、归一化前后和 token 选择，否则看似相同的公式可能作用于不同量。

可解码性、相关性和因果作用依次提出更强问题。一个线性分类器能读出“拒绝”标签，说明相关信息可读；移除方向后行为变化是干预证据；要归因到特定机制，还需排除一般损伤、模板信息与分布变化。

练习：X 是 128×4096，投影权重 W 是 4096×256。输出多大？

XW 为 128×256：token 数不变，每个 token 的特征维度变为 256。若拿单 token 作列向量，需使用 256×4096 的 Wᵀ。检查矩阵内侧维度是否一致，是阅读模型代码时成本最低的错误检测方法。

归一化原始机制：Root Mean Square Layer Normalization；Transformer 张量组织见 Attention Is All You Need。

Attention：匹配决定权重，Value 决定被混合的内容

先做两次不同意义的矩阵乘法，再让 softmax 引入非线性。

对按行堆叠的 X∈ℝᵀˣᵈ，某个头用三个权重得到 Q=XWQ，K=XWK，V=XWV。Q、K 为 T×dₖ，V 为 T×dᵥ。乘 QKᵀ 得到 T×T 的匹配分数：第 i 行是第 i 个 query 对各 key 的评价。除以 √dₖ，再加 mask，按行 softmax；每行必须至少有一个未被 mask 的有限 logit；这个前提下，所得 P∈ℝᵀˣᵀ 每行非负且和为 1。整行均为 −∞ 时，数学 softmax 未定义，实现需另行处理。最后 O=PV 得到 T×dᵥ。

P=softmax_row(QKᵀ/√dₖ + M)，O=PV 单行：pⱼ=exp(sⱼ/τ)/Σₖexp(sₖ/τ)，o=Σⱼpⱼvⱼ 教学例 q=(1,0)，k₁=(2√2,0)，k₂=(√2,0)，k₃=(0,√2) 除以 √2 后 s=(2,1,0)，τ=1，p≈(0.665,0.245,0.090)

这里额外引入温度 τ 是为了教学比较，它不是声称原始公式必有可调温度。τ 变小会加强已有分数排序；τ 变大使权重更平缓。softmax 对每行加同一常数不变，所以数值实现常先减行最大值以避免溢出。因果 mask 排除未来 token，padding mask 排除无效位置；“能注意到”与“被允许作为指令”是不同层面的规则。

在固定 P 时，O 对 V 是线性的；完整 self-attention 中 P 自己也依赖 X，因而整体非线性。多个头拼接后还要经过输出投影、残差和其他层。单个头内部的凸组合属性，也不意味着最终输出的每个特征都是原输入的凸组合。

把基础公式接到现代 LLM

RoPE（旋转位置编码）把 query/key 的成对坐标做与位置相关的正交旋转。用列向量看位置 m 的 query 与位置 n 的 key，点积为 (R(m)q)ᵀR(n)k=qᵀR(n−m)k，相对位置进入了匹配。每支向量自己的范数保持，但不同位置施加不同旋转，二者点积不保证保持。这个例子把第 4 节的正交性直接接到了模型机制。

以 Llama 3 论文描述的模型为例，其结构还采用 GQA、RMSNorm 与 SwiGLU。GQA 让一组 query heads 共享 key/value heads；不能按“每个 query head 都有独立 K/V”推算缓存规模。SwiGLU 把线性投影、非线性激活与逐元素乘法组成门控，不能化成一个固定矩阵。这些变化保留了线性代数骨架，同时要求逐层核对具体形状与实现。

位置旋转关系：RoFormer，第 3.2 节；模型结构例子：The Llama 3 Herd of Models，第 3.2 节。此处引用原始结构描述，不是对所有当前模型的概括。

attention 权重是计算中真实存在的中间量，但不是天然的因果解释或可信度分数。相同权重可对应不同 value 范数、输出投影和下游响应。讨论安全影响时应同时检查内容路径、实际干预与任务结果。

练习：T=100，dₖ=64，dᵥ=32。QKᵀ 和 PV 各是什么形状？

Q、K 是 100×64，QKᵀ 是 100×100；P 同样是 100×100，V 是 100×32，PV 是 100×32。缩放因子为 √64=8。若增加到 200 个 token，朴素分数矩阵的元素数会从 10,000 变为 40,000；这只是该矩阵规模变化，实际运行内存还依赖算法与实现。

原始 attention 公式与多头结构：Attention Is All You Need，第 3 节。

低秩权重更新与表示干预：相似的数学，不同的对象

LoRA 改权重，方向消融改激活；都需要问改动被限制在哪个子空间。

对列向量写法的权重 W∈ℝᵐˣⁿ，LoRA 用 ΔW=BA 参数化更新，其中 B∈ℝᵐˣʳ，A∈ℝʳˣⁿ，r 远小于 m、n。训练时冻结基础 W，学习低秩因子，并按配置施加缩放。rank(BA)≤r；参数量从 mn 变为 r(m+n)。例如 4096×4096 的矩阵，r=8 时因子有 65,536 个参数，相比完整矩阵的 16,777,216 个约为 1/256；这里只比较这一对矩阵的参数，不包含整个模型与优化器。

LoRA 不等于先对原 W 做截断 SVD。它限制的是更新的秩，基础权重可以满秩；学习的因子也不需要正交。低秩参数化并不自动提供安全隔离：很小的参数更新仍可能通过后续非线性和离散生成造成显著行为变化。要判断微调保留了什么，仍需任务与安全评估。

下文用 u 表示单位方向；它与上面 LoRA 的秩超参数 r 是不同对象。权重更新作用于矩阵，方向编辑作用于某个层和 token 的激活向量。

单位方向 u，‖u‖₂=1：P=I−uuᵀ 方向消融：h′=Ph=h−u(uᵀh)，于是 uᵀh′=0 部分消融：h′=h−αu(uᵀh)，0≤α≤1 方向注入：h′=h+βu；它移动表示，不是正交投影

把网络安全问题翻译成线性代数问题

翻译之后更容易检查假设；数学指标仍要落回攻击者、数据与操作后果。

考虑网络流量检测。每行是一条连接，每列是预先定义的统计特征；训练集拟合均值和协方差，然后用距离或线性模型给出分数。PCA 可以压缩或查看大规模变化，残差 x−QQᵀx 可以衡量偏离主要子空间的量。正常流量里的稀有业务也可能残差大，攻击若沿常见方向变化也可能残差小。因此评价应采用按时间或来源隔离的测试集、误报成本和具体威胁模型。

安全任务矩阵对象与计算可支持的判断必须补的证据
流量异常调查协方差、白化、子空间残差偏离当前样本定义的常态攻击标注、业务变化、基线误报率
行为或文本聚类embedding 距离、PCA 可视化某种表示中相近任务标签、近邻污染、信息丢失
恶意样本检测线性权重 w；margin=wᵀx+b特征空间中与决策面的关系攻击者是否能实现该特征变化
模型表征分析probe、SVD、方向干预可解码性、受控干预效果因果对照、能力代价、模型与数据范围

在线性二分类器里，决策边界是 wᵀx+b=0。从边界一侧到平面的最短欧氏距离为 |wᵀx+b|/‖w‖₂。若攻击者能在所有连续特征中任意移动，最短扰动沿 w；但网络包字段、字节序列或程序语义往往受离散和功能约束。几何最短扰动未必是可用攻击，需要把可实现集合写进问题。

合成检测器：w=(1,1)ᵀ，b=−3，x=(2,2)ᵀ margin=1；距边界=1/√2≈0.707 到边界的最短扰动 δ=−(margin/‖w‖²)w=(−0.5,−0.5)ᵀ

图中的几何只给出到边界，不保证越界；严格翻转需再略微移动并说明符号约定。若第二特征不可改，只能沿第一坐标移动，这次要改变 1 才能到边界。加入功能保持约束后，攻击成本和方向都会改变。这个小例子说明报告“最小攻击距离”时，必须说清楚是在原始输入、特征还是隐藏表示中计算。

密码学里也出现矩阵、秩、线性码和格，但运算可能发生在有限域或整数格中。实数域中的正交投影和欧氏最小二乘不能原样移植到有限域：例如 mod 2 下 1+1=0，几何长度的意义已经改变。本教程建立的是实数线性代数基础，后续学习这些领域要重新声明代数结构。

练习：PCA 图上正常与攻击混在一起，能否说原始表示不可分？

不能。二维投影可能删掉区分两类的低方差方向；原空间的线性或非线性可分性都不能仅由二维图否定。反过来，图上分开也可能由采集时间、来源或模板造成。应在独立测试数据上比较原始表示、投影表示和对照特征。

Agent 安全：信息进入模型，不等于获得行动权限

线性代数能分析表示和计算路径；信任边界要在整个执行链上观察。

一个典型 agent 从用户目标开始，读取网页或仓库，再生成工具参数，执行文件读写或网络请求。间接 prompt injection 的问题出现在不可信内容进入模型上下文后，被当成可影响目标或行动的指令。网页文本和系统指令最终都参与模型计算，这没有给网页作者授权；同样，进入 attention 的内容并不因此变成可信输入。

教程中的 attention 控件解释“少量权重也可能有影响”，方向投影控件解释“移除可疑方向也可能伤及正常信息”。这些机制能帮助提出攻击或防御假设，但没有直接证明某篇注入文本能导致越权。真正的端到端成功条件应该是明确事件，例如是否读取禁止文件、是否向未授权地址发送数据、是否改变用户未要求的目标，而不是某个隐藏坐标升高。

可以把研究问题分成三层。第一层是表示：能否从激活区分外部指令、引用文本和合法用户目标？第二层是行为：对照干预能否改变模型遵循外部指令的概率，正常任务受损多少？第三层是执行：即使模型生成了不当动作，系统策略是否拒绝？同一方法可能在一层有效、另一层无效；实验表应分别记录。

表示证据冻结层与 token 位置，独立数据测试 probe。
行为证据方向干预、随机方向和强度匹配对照。
执行证据固定工具策略，核对真实授权边界事件。

模型层与系统层可以互补。方向检测器给出风险分数，执行层用可信配置验证文件路径、目的地址、动作类型和授权；沙箱限制执行后的可达资源。风险分数不是授权令牌，沙箱也不能让任意允许动作都符合用户意图。以最小权限构造无真实敏感数据的合成任务，可以把数学分析连接到可审计的实验结果。

此处的防御组合是教程作者提出的研究拆分与实验建议。间接注入论文提供了攻击场景与实证；它没有证明教程中的投影、协方差或 attention 演示能检测或阻止这些攻击。

练习：某方法让“注入方向”分数下降 80%，能否报告攻击成功率下降 80%？

不能。隐藏分数与实际成功事件是不同指标，关系还可能因干预而改变。需要在相同威胁模型和独立任务集上测量攻击成功率、正常任务完成率与权限事件，并报告样本量、不确定性和失败案例。80% 只是题目给出的假设数字，不是本教程实验结果。

间接注入场景与原始实证：More than you've asked for（v1）。引用固定版本时采用该版本题名。

从会算到会研究：每一步都留下可检查的证据

先手算二维与三维，再用 NumPy 验证，最后把假设带进受控的模型实验。

复习的目标是能从公式预测一个可观察变化，而不只是认出名词。每个阶段都问四件事：张量在哪里、形状是什么、操作保留或丢失什么、哪些结论依赖假设。先用小数例检查符号，再用代码对随机数据验证恒等式，最后换成研究数据。不要跳过中心化、划分和单位这些“琐事”，它们经常比复杂公式更决定结论。

一段可复算的 NumPy 小实验

完整配套脚本包含六组 NumPy 教学实验与数值断言，可下载 linear_algebra_lab.py，按脚本说明本地运行。它扩展下面的最小二乘例子，仍使用合成数据，不连接真实 LLM 或网络环境。

import numpy as np

A = np.array([[1., 0.], [1., 1.], [0., 1.]])
b = np.array([1., 2., 2.])
x, _, rank, s = np.linalg.lstsq(A, b, rcond=None)
r = b - A @ x
U, sigma, Vt = np.linalg.svd(A, full_matrices=False)
A1 = sigma[0] * np.outer(U[:, 0], Vt[0])
print(x)                       # [0.66666667, 1.66666667]
print(A.T @ r)                 # 近似 [0., 0.]，浮点误差允许小偏差
print(rank, s)                 # 2；[sqrt(3), 1]
print(np.linalg.norm(A-A1))     # 默认矩阵 Frobenius 范数：1
print(sigma[0] / sigma[-1])     # sqrt(3)

可选扩展：为 A 加上逐渐变小的奇异方向，比较直接正规方程与 SVD 求解的误差；向样本加入重复特征，观察协方差秩；建立合成线性分类器，区分到边界的距离和功能约束下的可实现扰动。每次只改变一个条件，记录数据生成方式、随机种子、精度与阈值。代码输出是可预期的小例子，教程页面没有在浏览器训练模型。

连接到自己的 Agent 安全课题

选择一个开放权重模型和无真实敏感信息的 agent 任务。保存层、token 位置和激活提取方式，先问外部恶意指令是否线性可分。训练/测试按文档、任务和攻击模板分组，避免同源泄漏。若做方向干预，对比原模型、同范数随机方向、与候选方向正交的方向和不同强度；同时测量正常任务完成与禁止动作事件。若信号只在固定模板有效，结论就应停在该模板范围。

更深入的数学路线可以沿三条分支选择：数值线性代数学习 QR、稳定性和迭代法；统计学习学习协方差估计、核方法和随机矩阵；模型机制学习张量、自动微分、表示几何与干预实验。选哪一支由当前问题决定，不需要先把所有数学学完才开始研究。

综合练习：为什么低维线性 probe 成功，仍需要随机方向干预作为对照？

probe 只证明预测相关性。随意改变激活也可能损伤模型，导致拒绝或工具调用普遍减少；若候选方向与同范数随机方向效果相同，不能把变化归因于特定安全信号。应比较目标行为、正常能力和强度曲线，必要时做置换标签、位置匹配和跨模板测试。

来源、模拟范围与进一步阅读

数学结论、论文实验和教程推演分开核对。

本教程围绕 2026-10-12 核验的基础公式、原始机制与所引论文组织，不声称覆盖此日全部最新模型与安全研究。六个交互实验全部使用手工构造的二维矩阵、向量或合成协方差；attention 实验固定 Q/K 并改 V，方向实验使用读者指定的 u。页面没有接入真实模型、流量数据或攻击环境，图与数值不应被引用为模型实测性能。

  1. MIT 18.06 Linear Algebra：向量空间、四个基本子空间、投影、特征值和 SVD。适合重新建立几何与消元之间的连接。
  2. Mathematics for Machine Learning：第 2–5 章连接线性代数、解析几何、矩阵分解与向量微积分；PCA 的统计解释也可沿相关章节继续。
  3. Attention Is All You Need：核对 scaled dot-product attention、多头拼接与原始 Transformer 结构。教程使用基础机制，不把 2017 年配置等同于所有当前 LLM。
  4. Root Mean Square Layer Normalization：核对 RMSNorm 的均方根缩放与 LayerNorm 的差别。具体模型仍需检查自身实现和参数。
  5. LoRA: Low-Rank Adaptation of Large Language Models：核对低秩权重更新、基础权重冻结和参数化；不据低秩推断安全性。
  6. Refusal in Language Models Is Mediated by a Single Direction：方向提取与干预的论文实证。阅读时重点辨认模型集合、层/位置、数据和行为判定。
  7. More than you've asked for（v1）：间接 prompt injection 的场景与攻击证据。教程提出的表示分析与执行层拆分是研究组织建议，未报告防御实验。

现代结构补充来源为 RoFormer v5 的位置旋转公式，以及 Llama 3 v1 的结构描述。它们说明基础运算在较新模型中的具体落点，不能代替逐模型的实现核对。

最后自检：看到一个新的安全论文，你现在能追问什么？

它操作的是输入、权重、激活还是执行权限？每个矩阵形状是否一致？度量受什么缩放影响？所谓低秩是权重、更新还是数据？可解码性是否被误当成因果机制？攻击者的可实现集合是什么？评估是否按来源隔离，是否同时报告正常任务能力？这些问题把线性代数变成可用的研究判断工具。
